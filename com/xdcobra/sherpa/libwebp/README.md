libwebp for Android (xdcobra)

This directory contains the artifact layout for the `libwebp` AAR published by XDcobra. It includes libwebp and libsharpyuv native libs for all ABIs (arm64-v8a, armeabi-v7a, x86, x86_64) and public headers under `include/webp/`.
